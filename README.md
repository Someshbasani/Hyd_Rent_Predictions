# 🧠 Hyd_Rent Price Prediction using Linear Regression

This project demonstrates a **supervised machine learning** approach to predicting house prices using the **`hyd_v2.csv`** dataset. The core objective was to apply **Linear Regression**, perform **hyperparameter tuning**, and evaluate model performance using metrics like **R² score**.

---

## 📁 Dataset

The dataset `hyd_v2.csv` contains real estate features related to properties in Hyderabad, including attributes such as location, type_bhk, lift, and more.
